
﻿# ApplyFlow

ApplyFlow is a job application tracker designed to help job seekers organize and manage their job search in one place.

## Features

- **Overview Dashboard** — View a summary of your job search.
- **Application Tracking** — Keep track of job applications and their statuses.
- **Organized Workflow** — Manage applications through a centralized interface.

## Tech Stack

- React
- Vite
- React Router
- CSS

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/sakshamzalpuri/apply_flow.git
```

### 2. Navigate to the project

```bash
cd apply_flow
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal.

## Project Status

ApplyFlow is currently under development. Features and functionality may change as development progresses.
